The first public build of **Majora's Mask Randomizer Next**: the Majora's Mask Randomizer, rebuilt from the ground up in Rust with a new app for Windows, macOS, Linux and your web browser.

> [!WARNING]
> This is an **alpha**. Seeds are tested and beatable, and every setting from the original randomizer is in, but expect rough edges. Please report anything odd in [Issues](https://github.com/zmarotrix/Majoras-Mask-Randomizer-Next/issues), with your seed and settings string.

You need your own **Majora's Mask (USA)** ROM (`.z64`, `.n64` or `.v64`). It never leaves your computer, even in the browser version.

**First launch:** the apps aren't code-signed yet.
- **Windows:** if SmartScreen warns, choose **More info → Run anyway**.
- **macOS:** right-click the app, choose **Open**, then **Open** again.
- **Linux:** make the AppImage executable (`chmod +x`), then run it.

## What's in it

**Every setting from the original randomizer**, with the same logic. The new randomizer was checked against the original, ROM byte for ROM byte, on 34 test setups.

**A new app**
- **Guided layout:** presets, plain-English explanations, and search across every setting.
- **Classic layout:** the familiar tabs and boxes, if that's what you know.
- Works at phone width; light and dark themes.

**Every seed comes with**
- **A tracker** (`.html`): a spoiler-free checklist for playing the seed. It shows what you can reach right now with what you've found, time of day included, so it knows a check that only happens on Night 1. It also has item icons, hints next to the places they're about, reveal-one-answer-at-a-time, undo, and saved progress.
- **A rewritten spoiler log:** a hint summary, the playthrough, every check by area, and real place names.
- **Hash icons**, so racers can confirm they're on the same seed.
- Optionally, a small **patch** (`.mmrn`) others can apply to their own ROM (*File → Apply a patch*).

**Same seed, same ROM, everywhere:** Windows, macOS, Linux and the browser all build byte-identical ROMs from the same seed and settings.

**Also new**
- **A browser version** that makes seeds on your own device. No server, no upload.
- **A built-in manual:** every setting, preset and trick (458 of them), searchable (sidebar → *Manual*).
- **Shorter settings strings:** up to 4× shorter for the biggest presets.
- **A logic editor** that shows logic as places connected by exits. Logic files from older versions open directly. The settings-based changes the old randomizer made in hidden code are now visible in the logic.
- **Fixed: the All-Night Mask check.** The old randomizer required its Day 1 setup and the Curiosity Shop's night-only hours to overlap. They never do, so only junk was ever placed there.
- **Classic placement** now works as its own placement style.

## Good to know

- Patches from older versions (`.mmr`) can't be applied. Make the seed again with its settings instead.
- Settings files from older versions open directly (*File → Open settings*).
- Wii VC (`.wad`) output isn't included.
- Not yet tested on real Mac and Linux machines, or with touch on a phone. Reports welcome.
